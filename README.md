# Hairdresser Salon Demo Website

A modern, responsive demo website for a hairdresser salon featuring elegant design and smooth user experience.

## Features

- **Responsive Design**: Works perfectly on desktop, tablet, and mobile devices
- **Modern UI**: Clean and professional interface with gradient colors
- **Services Section**: Showcase of all available hair services with pricing
- **Gallery**: Display area for before/after photos and work samples
- **About Section**: Information about the salon and its expertise
- **Contact/Booking Form**: Easy-to-use appointment booking system
- **Smooth Navigation**: Scroll-based navigation between sections

## How to Use

Simply open `index.html` in any modern web browser to view the demo website.

## Sections

1. **Home/Hero**: Welcome banner with call-to-action button
2. **Services**: 6 different hair services with descriptions and pricing
3. **Gallery**: Showcase area for the salon's work
4. **About**: Information about the salon's history and values
5. **Contact**: Booking form and contact information

## Technologies Used

- HTML5
- CSS3 (with modern features like Grid and Flexbox)
- Vanilla JavaScript for smooth scrolling and form handling

## Browser Support

Compatible with all modern browsers including Chrome, Firefox, Safari, and Edge.
